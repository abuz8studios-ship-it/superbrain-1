**How to launch a non-interactive MUSE agent for scripted work:**
```
set MUSE_NO_AUTO_UPDATE=1
"C:\Users\wirec\AppData\Local\Programs\muse\muse.cmd" exec --json --prompt-file E:\path\prompt.txt
```
Notes:
- `MUSE_NO_AUTO_UPDATE=1` is important in scripts — without it the launcher can
  rewrite itself / switch binaries mid-run (verified in `.muse-launcher.ps1`
  main flow, tail of file).
- `--provider meta` (default) uses the stored Meta login; `--provider echo` is a
  no-cost dry-run mode for smoke-testing scripts.
- Exit code propagates through `muse.cmd` (`exit /b %ERRORLEVEL%`), so scripts
  can branch on it.
- An interactive session was NOT started; only `--help`, `--version`, and
